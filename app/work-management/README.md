# Work Management

This route is an additive work-management layer for the existing reporting product.

- Existing `/` daily reporting workflow remains unchanged.
- Existing `/admin` remains unchanged.
- `/work-management` provides a ClickUp/monday-style task workspace prototype with List and Board views, search, filters, statuses, priorities, assignees, projects, and quick task creation.
- Task data on this route is intentionally local demo state for the first product step; it does not alter the existing Supabase schema or existing reporting data.
